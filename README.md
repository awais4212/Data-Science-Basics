## 🛠️ Prerequisites

Before you begin, make sure you have the following installed:

- [Python 3.x](https://www.python.org/downloads/)
- [Jupyter Notebook](https://jupyter.org/install) or [Google Colab](https://colab.research.google.com/) *(no install needed)*
- Basic libraries:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

## ▶️ How to Use

**Option 1 — Run Locally:**
```bash
git clone https://github.com/awais4212/Data-Science.git
cd Data-Science
jupyter notebook
```

**Option 2 — Run on Google Colab (No Setup Needed):**

Click any `.ipynb` file → click the **"Open in Colab"** button at the top.
